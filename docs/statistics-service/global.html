Type Definitions

Transaction

Esquema que representa una transacción financiera. Cada transacción puede ser un gasto o un ingreso y puede estar asociada a una categoría, tener un valor original y estar compartida entre varios usuarios.
Properties:
Name Type Attributes Description
clientId String Identificador del cliente que creó la transacción. (Requerido)
name String Nombre o descripción de la transacción. (Requerido)
type "expense" | "income" Tipo de transacción: gasto o ingreso. (Requerido)
category ObjectId Referencia al modelo `Categoria` que clasifica la transacción. (Requerido)
value Number Valor actual de la transacción. (Requerido)
originalValue Number <optional>
 Valor original antes de ajustes o divisiones. (Opcional)
icon String <optional>
 Icono asociado a la transacción (por ejemplo, un emoji).
createdAt Date Fecha de creación de la transacción. (Por defecto: fecha actual)
sharedWith Array.<SharedWith> <optional>
 Lista de usuarios con los que se comparte el gasto.
splitType "equal" | "custom" Método de división del gasto: igualitario o personalizado. (Por defecto: `equal`)
totalParticipants Number <optional>
 Número total de participantes en el gasto compartido.
createdBy ObjectId <optional>
 Usuario que creó la transacción.
isShared Boolean Indica si la transacción es compartida. (Por defecto: `false`)
